# AI Collaboration Statement

> This statement tells the reader **what was done by machines, what was done by humans,
> and why the data here can still be trusted.**

## Short version

The **code, experiment execution, data analysis and documentation** in this repository
were produced with the assistance of AI systems.
**Humans set direction, made key judgements, and gave final review.**
All experimental data comes from **real hardware runs** — nothing is synthetic or interpolated.
There were two later corrections, **both to the summary table**: a column's semantics
(see `PITFALLS.md` item 8) and one mistyped step count (item 12).
The raw session cards were never hand-edited.
Every claim is backed by an evidence chain traceable to raw session cards.


## Who did what

| Step | Executed by | Note |
|---|---|---|
| Experiment design | **human + AI** | direction set by the human; parameters and controls drafted by AI, confirmed by the human |
| Training code | **AI** | `train.py` / `moe.py` written by AI; key sections reviewed by the human |
| Experiment execution | **AI** | run on real accelerators — no simulation, no interpolation |
| Data analysis | **AI** | all computed by script, never by hand |
| Documentation | **AI** | drafts written by AI, reviewed and edited by the human |
| **Pre-release review** | **a separate AI instance** | independently audited for leakage, citation completeness and data accuracy |
| **Final decision to publish** | **human** | — |

## Why this is acceptable

**Because the evidence chain does not depend on what the AI says.**

- Every number can be found in `data/summary.csv` or `data/session_cards/`
- The three figures can be **regenerated byte-for-byte** from the data file with `make_figures.py`
- The three scripts run as-is and their output can be checked
- The paired checks can be reproduced with `check_pair.py`

**The reader does not need to trust any narrative — only to run it once.**

## What the AI got wrong

**A statement that only says "AI assisted" without saying "how often the AI was wrong" is dishonest.**

During this work the AI was **proven wrong more than ten times**, including:

- **splicing numbers from two different windows into one sentence** → caught by independent review (see `PITFALLS.md` item 1)
- **"set" is not "in effect"**: an injected bias was overwritten on ckpt restore while the log reported success → item 4
- **silent platform degradation**: `float64` returned 0 on one accelerator, so the metrics were constant while training looked normal → item 7
- **no re-scan after a follow-up measurement**, leaving two sections of one document contradicting each other → item 9
- **batch text replacement silently failing** twice while we believed the edits had landed → caught by independent review (item 10)

**All of these are recorded in `PITFALLS.md`.**
We publish them because **a narrative that never errs is more suspicious than a process that errs and checks itself.**

## Data integrity

- Every session card is written automatically by the training script at the end of a run; none were hand-edited
- The `status` field records whether a run was judged unusable (7 runs are voided and **kept, not deleted**)
- Training logs are archived in the experiment directory and available on request

**Please open an issue.** This is work in progress; undiscovered errors cannot be ruled out.
